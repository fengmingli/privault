# Privault 创建目录、密码规则与步骤体验设计

日期：2026-10-31  
状态：已获用户选择方案 A，待实现

## 1. 目标与范围

优化真实保险库创建流程：

1. 创建时即可通过系统原生目录选择器选择 `vault.db` 和 `vault.meta` 的保存目录，不再要求先创建到默认目录再迁移。
2. 新建主密码至少 8 位，并在大写字母、小写字母、数字、特殊字符中至少包含 3 类。
3. 创建和恢复访问时，主密码及确认密码均可用小眼睛切换显隐。
4. 创建第一步按钮由“继续”改为“下一步”。

不包含：网络盘/U 盘支持、手动粘贴任意路径、自动合并冲突、改变已有密码、恢复密钥格式变化或安装包签名发布。

## 2. 已选方案

采用方案 A：扩展 `vault_create`，让 Rust 在创建前校验可选目录，并直接在目标目录创建保险库。

不采用先创建再迁移，也不在创建前单独提交路径配置。

## 3. 创建页面与数据流

### 3.1 保存位置

创建第一步新增“保存位置”区域：

- 默认显示当前默认保存目录。
- “选择保存文件夹”调用现有 Rust 原生目录选择命令 `storage_choose_location`。
- 选择成功后保留该目录用于本次创建，并允许“恢复默认目录”清除自定义选择。
- 原生选择器取消时不改变当前选择，不调用创建或路径修改命令。
- 不提供路径文本输入框。
- 浏览器 Demo 仅显示内存模式说明，不展示伪造路径或真实目录按钮。

`CreateVaultFlow` 的创建回调变为：

```text
onCreate(masterPassword, destination: string | null)
```

其中 `null` 表示默认目录。`VaultGateway.create` 和 Tauri 命令保持同一可选参数约定；旧调用不传目录时行为不变。

### 3.2 创建步骤

1. 用户选择目录（可选）。
2. 输入主密码和确认密码，可分别切换显隐。
3. 前端校验密码规则和确认一致性。
4. 点击“下一步”，前端调用 `vault_create(masterPassword, destination)`。
5. Rust 校验并直接创建，返回一次性恢复密钥。
6. 第二步保存恢复密钥并解锁，流程与现有实现一致。

## 4. Rust 创建与失败回滚

`VaultManager` 新增创建到可选目录的能力，同时保留现有 `create(masterPassword)` 作为默认目录入口。

有自定义目录时：

1. 新密码规则校验。
2. 使用现有 `validate_destination` 校验固定卷、权限、危险链接、根目录、空间和同名文件冲突。
3. 暂存原工作区与配置，仅在校验成功后切换到候选工作区。
4. 复用现有创建逻辑，在候选目录生成随机 DEK、双密钥槽、`vault.db` 和 `vault.meta`。
5. 数据库和元数据成功后，最后原子写入 `config.json`。
6. 任一步骤失败，恢复暂存的工作区与配置，不静默回退到默认目录；错误仍使用现有稳定错误码和脱敏消息。

默认目录创建继续使用现有路径。原生目录选择器本身不修改配置。

## 5. 新密码规则

仅约束新设置的主密码：创建、修改主密码、恢复访问。已有保险库的旧密码解锁不受影响，不强制迁移或改密。

规则：

- 至少 8 个 Unicode 码点。
- 以下四类至少包含三类：
  - ASCII 大写字母 `A-Z`
  - ASCII 小写字母 `a-z`
  - ASCII 数字 `0-9`
  - 非空白且非 ASCII 字母数字的特殊字符

前后端均按 Unicode 码点计数，避免 JS UTF-16 长度与 Rust 字符数不一致。确认密码必须完全相同。

示例：

- `Abcdef1!`：通过。
- `abcdefgh`：拒绝，仅一类。
- `Abcdefg1`：通过，三类。
- `Ab1!`：拒绝，不足 8 位。

前端提示与错误文案说明完整规则，不再显示“至少 12 位”。Rust 在创建、改密和恢复时执行独立校验，不能仅靠前端绕过。

## 6. 密码显隐组件

新增可复用的密码输入组件：

- 默认 `type="password"`。
- 点击 Eye / EyeOff 小眼睛切换 `type="text"`。
- 具有明确可访问名称，例如“显示主密码”“隐藏主密码”“显示确认密码”。
- 切换只改变当前字段，不影响另一个字段。
- 保持禁用、自动聚焦和现有样式，不复制密码、不改变保存值。

用于创建和恢复访问的主密码及确认密码。解锁已有保险库不属于本次“设置密码”范围，可保持现有输入。

## 7. 错误与边界

- 无效目录在创建前返回错误，不改变默认工作区或配置。
- 目标存在同名 `vault.db` / `vault.meta` 时拒绝，不覆盖、不合并。
- 密码不符合规则时不发起创建命令；直接调用 Rust 也同样拒绝。
- 创建失败保留用户当前输入和目录选择，便于修正后重试。
- 原生目录选择取消不是错误，不显示错误提示。
- 浏览器 Demo 不触发真实目录或 Tauri 命令。

## 8. 测试与验收

- 默认路径展示、原生选择成功/取消、恢复默认、Demo 边界。
- 自定义目录传递给 `vault_create`。
- 至少 8 位和至少三类字符的接受/拒绝组合、确认一致性。
- 两个密码字段独立显隐及可访问名称。
- “下一步”按钮和异步错误保留。

- 新密码规则覆盖长度、类别、创建、改密和恢复；旧密码解锁不受影响。
